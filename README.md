# DevShed

Unified 6-in-1 developer & SRE utility suite deployed via GitHub Pages:

1. **Browser PDF Tools** (`browser-pdf-tools/`) — Merge, split, and rearrange PDFs client-side.
2. **Doc2MD** (`doc2md-action/`) — Convert documents to Markdown in the browser or as a GitHub Action.
3. **Self-Healing Deployment** (`self-healing-deployment/`) — Blue/green deployment pipeline & rollback dashboard.
4. **Multi-Cloud Free Tier** (`multicloud-free-tier/`) — Provision and monitor free-tier servers across AWS, GCP, Azure, and Oracle Cloud.
5. **Study Brainrot Generator** (`study-brainrot-generator/`) — Generate short vertical captioned study videos from Wikipedia.
6. **Minecraft Server GitOps** (`minecraft-server-gitops/`) — Declarative 24/7 Minecraft server management via Git.

Open the root `index.html` (or the GitHub Pages URL) to pick any of the 6 tools from one launcher.
