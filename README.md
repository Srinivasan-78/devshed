# DevShed

Unified 3-in-1 developer & SRE utility suite deployed via GitHub Pages:

1. **Browser PDF Tools** (`browser-pdf-tools/`) — Merge, split, and rearrange PDFs client-side.
2. **Doc2MD** (`doc2md-action/`) — Convert documents to Markdown in the browser or as a GitHub Action.
3. **Self-Healing Deployment** (`self-healing-deployment/`) — Blue/green deployment pipeline & rollback dashboard.

Open the root `index.html` (or the GitHub Pages URL) to pick any of the 3 tools from one launcher.
