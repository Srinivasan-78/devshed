Multi-Cloud Free Tier

FastAPI + Ansible dashboard to provision and monitor free-tier compute across AWS, GCP, Azure, and Oracle Cloud. (Requires Python/Docker backend — launch locally below.)

Run Locally

cd multicloud-free-tier/api
cp .env.example .env
docker build -t multicloud-free-tier .
docker run -p 8000:8000 --env-file .env multicloud-free-tier
