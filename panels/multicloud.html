Multi-Cloud Free Tier

Flask + Postgres + Ansible + Terraform dashboard that provisions and auto-destroys free-tier compute instances across clouds (requires Docker Compose locally).

Run Locally with Docker Compose

cd multicloud-free-tier
cp api/.env.example api/.env
# Generate SECRET_KEY and FERNET_KEY:
python -c "import secrets; print('SECRET_KEY=' + secrets.token_urlsafe(48))"
python -c "from cryptography.fernet import Fernet; print('FERNET_KEY=' + Fernet.generate_key().decode())"
docker compose up --build
# Open http://localhost:8000
